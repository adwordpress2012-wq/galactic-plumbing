# Galactic Plumbing Build Skill

## Role
Build a clean, local, high-converting one-page plumbing website for Galactic Plumbing Services.

## Framework
- Next.js
- TypeScript
- Tailwind CSS
- Deploy on Vercel

## UI Rules
- White background.
- Blue/navy accents.
- Clean cards, rounded corners, strong spacing.
- Mobile-first layout.
- Hero must show Luke/plumber photo with van/logo on right.
- Keep the design local and trustworthy, not sci-fi/gaming.
- Use “Galactic” as a memorable name, not an overdone space theme.

## UX Rules
- The main outcome is fast booking and fewer missed jobs.
- Micah is a booking assistant, not the main brand.
- Luke personally handles quotes and onsite work.
- No pricing shown on the Galactic Plumbing website.
- No over-advertising QuoteOS.
- QuoteOS/DOS only appears subtly near the bottom/footer.

## CTA Rules
Primary CTA: Micah — Take Your Booking
Secondary CTA: Call Now
Emergency CTA: 24/7 Emergency Service / Call Luke Now

## Copy Rules
Use plain Australian English.
Keep copy local, fast, and trust-first.
Avoid heavy AI language.
Use phrases like:
- Fast local plumbing services
- Micah takes your booking so Luke never misses a job
- Luke personally handles every quote and onsite job
- Simple. Transparent. No runaround.
